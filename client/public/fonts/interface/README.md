# Interface Fonts

This directory contains the Simplified Chinese webfont subsets used by the optional Claude and ChatGPT interface styles.

- Noto Serif SC 400 and 600
- Noto Sans SC 400, 500, and 600
- Package source: Fontsource 5.3.0
- Upstream project: https://fonts.google.com/noto/specimen/Noto+Serif+SC and https://fonts.google.com/noto/specimen/Noto+Sans+SC
- Package source URLs: https://www.npmjs.com/package/@fontsource/noto-serif-sc and https://www.npmjs.com/package/@fontsource/noto-sans-sc
- License: SIL Open Font License 1.1, included as `OFL-1.1.txt`
